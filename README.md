# Data Science 500 · Analysis Exercises

A notebook collection covering flight data, sales data, cleaning, and visual exploration.

## ✨ Highlights

- `CA.ipynb` cleans and renames airline columns, then creates several plots.
- Sales and DataFrame exercises are included alongside CSV files.
- All analysis material is under `DATA-SCIENCE-main/`.

## 🚀 Getting started

Install Python 3 and a notebook environment. A minimal starting environment is:

```sh
python -m pip install jupyterlab pandas matplotlib
cd DATA-SCIENCE-main
python -m jupyterlab
```

Open `CA.ipynb` and run its cells in order. Keep the kernel working directory alongside the datasets.
